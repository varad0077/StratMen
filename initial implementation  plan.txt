# StratMen Foundation — Complete Full-Stack Build

Build the complete StratMen Foundation website + StratChat portal as a React 19 + Vite 8 SPA backed by Supabase (PostgreSQL + Auth + Realtime) and Cloudinary.

## User Review Required

> [!IMPORTANT]
> **This is a massive build** — approximately **70+ files** spanning database migrations, Supabase config, services, hooks, Redux store, layouts, views, and components. The frontend alone will be ~50 files.

> [!IMPORTANT]
> **Database Setup is Manual**: You will need to run the consolidated SQL migration script in the **Supabase SQL Editor** yourself. I will generate a single combined `.sql` file for convenience, but Supabase database cannot be provisioned from code.

> [!WARNING]
> **Supabase Credentials Required**: Your `.env` file already contains valid keys (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_CLOUDINARY_CLOUD_NAME`, `VITE_CLOUDINARY_UPLOAD_PRESET`). I will use these directly.

> [!IMPORTANT]
> **Google OAuth**: The Google OAuth callback (`/auth/callback`) requires a configured Google OAuth provider in your Supabase Dashboard → Authentication → Providers → Google. Have you set this up?

## Open Questions

> [!IMPORTANT]
> 1. **Cloudinary Upload Preset**: Is `stratmen_posts` already configured as an **unsigned** upload preset in your Cloudinary dashboard? (Required for client-side uploads.)
> 2. **TailwindCSS Version**: The spec says TailwindCSS 4. TailwindCSS v4 uses a new CSS-first configuration model (no `tailwind.config.js`). Shall I proceed with TailwindCSS 4, or would you prefer TailwindCSS 3 which has broader shadcn/ui compatibility?
> 3. **Admin Portal**: The spec lists an **integrated Admin Portal inside StratChat** at `/stratchat/admin`. Should admin see separate tabs (Join Requests, Allowlist, Users, Content, Audit Logs) as a tabbed interface, or as separate sub-routes?
